# agent-interview

一份面向 `AI Agent / LLM Agent 工程师` 面试准备的学习资料仓库，内容覆盖基础概念、Agent 设计模式、工具调用、记忆、RAG、规划、多 Agent、系统设计、评估、安全、训练对齐、生产环境和前沿热点。

这份资料不是单纯堆概念，而是尽量按“面试能说出来”的方式整理。很多题目都补了：

- `核心结论`
- `理解重点`
- `标准回答示例`
- `工程化视角`
